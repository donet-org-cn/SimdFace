# SimdFace 1.1.0

## 中文

- **核心库活体核验**。新增 `FaceVerificationSession`，接收 RGB24 帧，检查随机转头及闭眼睁眼或张嘴合嘴，结合 MiniFASNetV2 防翻拍分数和 Face Mesh 关键点，分别返回身份与活体结论。
- **摄像头测试台**。在视频框内提示当前动作，支持手机通过局域网 HTTPS 使用摄像头。YuNet 和 SFace 可走 Vulkan 或 CPU，防翻拍和人脸网格在 CPU 推理。
- **模型与文档**。仓库包含两份新增模型及其许可证。核心包带中文 XML API 文档，提供中英文接入说明。
- **自动发布**。GitHub Actions 校验版本和包内容，测试 CPU 推理及软件 Vulkan 设备的识别。Vulkan 硬件推理在 RTX 3060 上验证。流水线通过 NuGet.org Trusted Publishing 发包，验证公开下载后创建 GitHub Release。

## English

- **Core liveness API.** `FaceVerificationSession` accepts RGB24 frames and checks randomized head turns and eye or mouth actions. It uses MiniFASNetV2 for anti-spoof scoring and Face Mesh for landmarks, with separate identity and liveness results.
- **Camera lab.** In-frame prompts guide the challenge. Phones on the same network can connect over HTTPS. YuNet and SFace support Vulkan and CPU inference. Anti-spoof and face mesh inference run on the CPU.
- **Models and documentation.** The repository includes the camera model weights and licenses. The package includes Chinese XML API documentation, with bilingual integration instructions in the repository.
- **Automated release.** GitHub Actions validates the version and package, tests CPU inference, and checks software-only Vulkan device detection. Vulkan hardware inference was tested on an RTX 3060. The workflow publishes through NuGet.org Trusted Publishing and creates a GitHub Release after verifying the public download.
